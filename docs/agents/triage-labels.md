# Triage labels

Use these strings in each issue's `Status:` line.

| Role | Tracker value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill requests a triage role, use its tracker value.
Wayfinding claim and resolution states follow issue-tracker.md.
